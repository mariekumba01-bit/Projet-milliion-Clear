Abonnement — lien de paiement par mois

Modèle « lien de paiement par mois » (SasPay, mobile money / carte) : envoi J1, rappel J7, suspension d'accès J21 si non réglé. Prix = hypothèses de test, non validées commercialement. Sans clé API SasPay, le lien est créé en mode manuel (créé depuis le tableau de bord SasPay, puis versé dans l'app).

Intégrations

Pennylane (OAuth2 partenaire)

Flow authorization code réel (app.pennylane.com/oauth) : scopes customer_invoices:readonly transactions:readonly customers:readonly bank_accounts:readonly, refresh token à rotation stricte, jetons chiffrés AES-256-GCM au repos. Requiert PENNYLANE_CLIENT_ID/SECRET (accès partenaire). La synchronisation importe factures ouvertes + transactions bancaires dans votre portefeuille.
